Help & Instructions

This app retrieves data from goolge drive called monitor.txt. But to retrieve that a self hosted proxy has to be created at cloudflare.com. Login using google account diskapi2 at https://workers.cloudflare.com/ On the left menu click Compute then workers/pages and flat-hall-df36 is the worker app. DATA SOURCES The worker is tried first. If it fails, the app falls back to fetching the file straight from the Google Drive API. The direct fetch needs monitor.txt shared as "Anyone with the link" and a Drive API key. URL FLAGS (add to this page's address) ?source=drive force the direct Drive fetch (same as ?direct=1) ?source=worker force the worker only, no fallback ?apiKey=KEY supply the Drive API key for this session The status line under the buttons names the source that answered, and Debug Info lists anything that failed on the way.
